%%% Main code %%%  
File 'H2waterChina.m' contains the main code under SSP2-2C pathway.  
File 'H2waterChina15C.m' contains the SSP2-1.5C pathway code.  
File 'MonteCarlo.m' contains the Monte Carlo simulation code.  
All CSV files serve in 'Data' folder are the input databases.  
The recommended environment is MATLAB R2016b.
